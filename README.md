# AirTransfer — iPhone ⇄ Windows Laptop Wi-Fi File Drop

A lightweight, zero-configuration local network file sharing tool built specifically for seamless transfer of photos, 4K videos, and files between iPhone and Windows Laptop.

## Features
- **No iPhone App Required**: Works directly in iPhone Safari by scanning a QR code or visiting the local URL.
- **Zero Internet Usage**: Transfers over your local Wi-Fi router at maximum speed (20–50+ MB/s).
- **Original Quality**: Preserves full resolution of iPhone photos (.HEIC / .JPG) and high-bitrate 4K HDR videos.
- **Bi-directional**:
  - iPhone ➔ Laptop: Tap to choose Photos/Videos or Files with live progress and transfer speed.
  - Laptop ➔ iPhone: Download any file saved on laptop back to iPhone.
- **Direct Save Location**: All received files are saved in `C:\Users\aquib\Downloads\iPhone_Transfers`.

## How to Use
1. Double click **`Start-AirTransfer.bat`** on your Desktop.
2. A terminal window and laptop browser will open showing a **QR Code**.
3. Open your iPhone's **Camera** and scan the QR code.
4. Tap the link to open Safari:
   - Tap **"Photos & Videos"** or **"Browse Files"** to select items.
   - Watch the live upload progress.
5. All files will be saved in your laptop's **Downloads > iPhone_Transfers** folder!
